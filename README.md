# UNO-for-beginner
A fun and simple UNO game for beginners.

- Nicolas Schneider
- Thasika Sivaramalingam

## User Stories
### As a player, I want to start a new game, so that i can play with a new card deck
### As a player, I need to see my cards, so that i know which card i can play
### As a player, I want to choose a card, so that i can make a move
### As a player, I want to be able to select only cards from my hand, so that i cannot choose an unavailable card
### As a player, I want to check if a card can be played, so that i cannot make an inavlid move.
### As a player, I want the game to validate may color choice, so that i can only choose a valid color
### As a player, i want to be able to save my game so that i can continue it later
### As a player, i want to load a save game, so that i can continue my previous game
### As a player, i want my game to be saved automatically when i exist, so that i do not lose my progress
