# UNO-for-beginner
A fun and simple UNO game for beginners.

Our application is a card game where a human player plays against the computer. The game must follow the rules and check if each move is valid. Players can see their cards, save and load their games, and view the statistics to see how often the human player and the computer have won.

## User Stories
### As a player, I want to start a new game, so that i can play with a new card deck (Thasika Sivaramalingam)
### As a player, I need to see my cards, so that i know which card i can play (Thasika Sivaramalingam)
### As a player, I want to choose a card, so that i can make a move (Thasika Sivaramalingam)
### As a player, I want to be able to select only cards from my hand, so that i cannot choose an unavailable card (Subidsha Yoharajah)
### As a player, I want to check if a card can be played, so that i cannot make an inavlid move. (Subidsha Yoharajah)
### As a player, I want the game to validate may color choice, so that i can only choose a valid color (Subidsha Yoharajah)
### As a player, i want to be able to save my game so that i can continue it later (Nicolas Schneider)
### As a player, i want to load a save game, so that i can continue my previous game (Nicolas Schneider)
### As a player, i want my game to be saved automatically when i exist, so that i do not lose my progress (Nicolas Schneider)
### As a player, I want to view the game statistics, so that I can see how often the human player and the computer have won (Nicolas Schneider)
